## Issues and discussions

Bug reports, questions, and feature requests are welcome via Issues and
Discussions. For commercial inquiries (source license, OEM / white-label,
integration), see [docs/licensing.md](docs/licensing.md).

## Pull requests

We occasionally accept small documentation corrections. By submitting a pull
request or any other contribution to this repository, you agree that your
contribution is assigned to StreamXLS LLC, which may use, modify, relicense, and
distribute it without restriction or obligation to you. If you cannot agree to
this, please open an Issue describing the change rather than submitting a pull
request.
