# StreamXLS documentation

The curated documentation site is at [streamxls.com/docs](https://streamxls.com/docs). This folder holds the complete reference documentation in the repository. Pick the doc that fits what you need:

- **[quickstart.md](quickstart.md)** — start here. Your first `=RTD()` formulas across status, account, market data, positions, and orders, with the most common fields and the market-data version floor.
- **[detailed-instructions.md](detailed-instructions.md)** — the formulas in depth: contract specification (options, futures, forex, combos, ConID), staging orders, cell states & lifecycle, and troubleshooting.
- **[reference.md](reference.md)** — the exhaustive reference: every topic and category token, market-data field, contract key, StageOrder write key, order and position field, status and metadata field, account key, configuration key, and cell-error value.
